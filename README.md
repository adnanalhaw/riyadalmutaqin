# رياض المتقين — منصة دعوية

منصةٌ دعويةٌ لقناة **رياض المتقين** («القرآن والسنّة بفهم سلف الأمّة»)، مبنيةٌ على Cloudflare بتكلفةٍ منخفضة.

## نظاما الدخول

الموقع مبنيٌّ على **نظامين للدخول** إضافةً إلى الواجهة العامة:

- **المتعلّم (student):** تسجيل، حضور البث المباشر، مكتبة حفظ الفيديوهات، مكتبة المقاطع، المكتبة الصوتية.
- **المعلّم (teacher):** إدارة الدروس المباشرة (لايف + مسجّل) مع النشر التلقائي على يوتيوب، صفحة المونتاج، تحليل البيانات، والنشر على القنوات.
- **الواجهة العامة:** الصفحة الرئيسية (الرؤية والأهداف)، عن الموقع، بطاقة المشاركة، الدروس والمقاطع والمكتبة الصوتية.

## حالة المشروع — المراحل

التنفيذ يتمّ **مرحلةً واحدةً في كل مرة**:

- [x] **المرحلة ٠ — التأسيس:** بنية Worker + ربط D1/R2 + النشر التلقائي + نقطة `/api/health`.
- [x] **الواجهة والهيكل:** إعادة بناء الموقع بهوية رياض المتقين (كحلي/ذهبي)، نظاما الدخول (متعلّم/معلّم)، وكل الصفحات المطلوبة كواجهات حقيقية (مع بيانات تجريبية حيث تنتظر الواجهة الخلفية).
- [x] **المرحلة ١ — قاعدة البيانات:** مخطط كامل (مستخدمون/جلسات/دورات/دروس/تقدّم/مكتبة/مقاطع/صوتيات/منشورات/تدقيق…) + ترحيلات D1 + بيانات تجريبية (`migrations/`).
- [x] **المرحلة ٢ — مصادقة المتعلّم/المعلّم (آمنة) + الجلسات:** تشفير PBKDF2، كوكيز HttpOnly/Secure/SameSite، حدّ معدّل المحاولات، حماية واجهات المعلّم، صفحة «حسابي».
- [x] **المرحلة ٣ — قيمة المتعلّم:** مكتبة الحفظ (bookmarks)، متابعة التقدّم، وربط صفحات الدروس/المقاطع/الصوت/المكتبة ببيانات D1 الحقيقية.
- [x] **المرحلة ٤ — لوحة المعلّم:** إحصاءات حقيقية من القاعدة (دروس/متعلّمون/مقاطع/صوتيات)، شريط جانبي مشترك، حماية بدور المعلّم.
- [x] **المرحلة ٥ — إدارة المحتوى (CRUD):** الدروس (إنشاء/تعديل/حذف + استيراد يوتيوب بصورة/عنوان/دكتور + رفع الأغلفة لـR2)، والمقاطع والمكتبة الصوتية (مع رفع الصوت لـR2)، وسجلّ تدقيق لكل إجراء.
- [x] **المرحلة ٦ — تكامل يوتيوب:** تدفّق OAuth كامل (ربط/فكّ/حالة)، تخزين الرموز وتحديثها تلقائياً، والرفع التلقائي الفعلي للفيديو إلى قناة المعلّم (videos.insert). يتطلّب إدخال مفاتيح Google (انظر الإعداد أدناه).
- [x] **المرحلة ٧ — البث المباشر (لايف) عبر يوتيوب:** المعلّم يلصق معرّف/رابط يوتيوب لايف، الزائر يشاهده في `/live`، وزر «إنهاء البث ونشر كمسجّل» يحوّله إلى درس منشور. (لا WebRTC ذاتي — متعمّد لتكلفة Cloudflare المنخفضة.)
- [x] **المرحلة ٨ — استوديو المونتاج (داخل المتصفّح):** تحميل فيديو، قص (بداية/نهاية)، إضافة شعار وعنوان وسطر فرعي فوق الفيديو، وتصدير WebM عبر Canvas + MediaRecorder — بلا خادم. (دمج عدّة مقاطع لاحقاً.)
- [x] **المرحلة ٩ — تحليل البيانات + النشر على القنوات:** تحليلات حقيقية من D1 (الدروس/المتعلّمون/مرّات الحفظ/الإكمالات + أداء كل درس + تسجيلات آخر ٧ أيام)، ولوحة نشرٍ موحّدة على `channel_posts` (إنشاء/جدولة/قائمة/حذف). تيليجرام يُنشَر تلقائياً عند ضبط أسراره؛ بقيّة القنوات تُحفظ في قائمة الإصدار ويُربط تسليمها التلقائي تباعاً.
- [x] **المرحلة ١٠ (جزئياً) — الأمان وSEO:** ترويسات أمان لكل صفحة (CSP، nosniff، X-Frame-Options، HSTS، Referrer/Permissions Policy)، `robots.txt`، `sitemap.xml`، وسوم Open Graph/Twitter، صفحة ٤٠٤، وأيقونة الموقع. (يبقى للإطلاق: ربط Cloudflare الفعلي ومراجعة نهائية.)
- [x] **اكتمال الإدارة (2026-08):** إعدادات الموقع (روابط التواصل)، اعتماد الصوتيات، الدورات، رفع كتب PDF باعتماد المدير، وإعادة هندسة الصفحة الرئيسية.
- [x] **الإشعارات الصوتية (2026-08):** نغمات Web Audio مع تذكيرات الصفحة، زر كتم في الترويسة، تنبيه مواقيت اختياري، وجرس إشعارات للأدوار المسجّلة.
- [x] **أذكار/مساجد أغنى + اشتراك مساجد (2026-08):** أقسام أذكار موسّعة، مفضّلة/مشاركة/TTS، إقامة المساجد، منتصف الليل/الثلث الأخير، وصفحات مساجد Free/Pro (**بلا جمع تبرعات** — الهدف مليون دينار عبر SaaS + رزق B2B).

## الإعداد على Cloudflare (مرّة واحدة)

```bash
# 1) سجّل الدخول
npx wrangler login

# 2) أنشئ قاعدة البيانات وضع database_id في wrangler.toml
npx wrangler d1 create riyad_db

# 3) أنشئ مخزن الملفات
npx wrangler r2 bucket create riyad-media

# 4) انشر
npm run deploy
```

### إعداد تكامل يوتيوب (OAuth)

1. في [Google Cloud Console](https://console.cloud.google.com/): أنشئ مشروعاً.
2. فعّل **YouTube Data API v3** (APIs & Services → Library).
3. اضبط شاشة الموافقة (OAuth consent screen) — نوع External، وأضِف نفسك كـ Test user.
4. أنشئ **OAuth client ID** (نوع: Web application)، وأضِف Authorized redirect URI:
   `https://<نطاقك>/api/teacher/youtube/callback`
5. أضِف المفتاحين كأسرار:

   ```bash
   npx wrangler secret put GOOGLE_CLIENT_ID
   npx wrangler secret put GOOGLE_CLIENT_SECRET
   ```

   وللتطوير المحلي ضعهما في `.dev.vars`.
6. من لوحة المعلّم → الدروس → «ربط حساب يوتيوب». بعدها يُرفع أي فيديو مسجّل تلقائياً إلى قناتك.

> النطاقات المطلوبة: `youtube.upload` و`youtube.readonly`. الرموز تُحفظ في جدول `youtube_accounts` (قاعدة خاصة) وتُحدَّث تلقائياً.

### إعداد النشر — كل معلّم على قناته

من `/teacher/publish` (متاح أيضاً لمدير الموقع):

1. **تيليجرام الخاص بك:** أنشئ بوتاً عبر @BotFather، أضِفه لمشرف قناتك، ضع `bot_token` و`chat_id` في «قنواتي الخاصة».
2. **باقي المنصّات:** أنشئ Webhook في Make/Zapier/n8n مربوطاً بحساباتك، والصق الرابط في نفس الصفحة.
3. **يوتيوب (رفع فيديو):** من `/teacher/lessons` → ربط OAuth (لكل معلّم حسابه في `youtube_accounts`).

أسرار الموقع `TELEGRAM_*` و`PUBLISH_WEBHOOK_URL` أصبحت **احتياطاً اختيارياً** فقط إن لم يربط المستخدم قناته.

1. أنشئ بوتاً عبر [@BotFather](https://t.me/BotFather) واحصل على رمز البوت.
2. أضِف البوت إلى قناتك/مجموعتك واحصل على معرّف الدردشة (`chat_id`).
3. أضِف السرّين:

   ```bash
   npx wrangler secret put TELEGRAM_BOT_TOKEN
   npx wrangler secret put TELEGRAM_CHAT_ID
   ```

   وللتطوير المحلي ضعهما في `.dev.vars`.

> عند اختيار «تيليجرام» مع «نشر الآن» تُرسَل الرسالة فوراً عبر Bot API. بقيّة القنوات (يوتيوب/تيك توك/إنستغرام/فيسبوك/إكس) تُسلَّم عبر `PUBLISH_WEBHOOK_URL` إن ضُبط، مع إمكانية **إعادة التسليم** من لوحة النشر وحالة ربط واضحة لكل وسيط.

### النشر التلقائي عبر GitHub

أضف السرّين التاليين في إعدادات المستودع (Settings → Secrets → Actions):

- `CLOUDFLARE_API_TOKEN`
- `CLOUDFLARE_ACCOUNT_ID`

وبعدها كل دفعةٍ إلى `main` تُنشَر تلقائياً (راجع `.github/workflows/deploy.yml`).

### Webhook توزيع المنشورات (اختياري — كل المنصّات دفعة واحدة)

بدل ربط كل منصّة على حدة: أنشئ سيناريو في وسيط أتمتة (Make / Zapier / n8n) يبدأ بـ
"Webhook — Custom" وانسخ رابطه، ثم أضِفه سرّاً باسم `PUBLISH_WEBHOOK_URL` في
إعدادات المستودع (Settings → Secrets → Actions). بعدها كل «نشر الآن» أو منشور
مجدول يُرسَل للوسيط بحمولة JSON واحدة `{channels, content, media_url}` والوسيط
يوزّعه على يوتيوب/تيك توك/فيسبوك/إكس حسب توجيهك داخل السيناريو.
