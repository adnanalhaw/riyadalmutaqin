# 📜 قرارات المالك المُلزمة — رياض المتقين

> يقرؤه أي وكيل/مطوّر قبل العمل. آخر تحديث: 2026-08-12.

## 1) العلاقة مع رزق (قرار 2026-08-12)

- **المنصّتان منفصلتان كلياً في الكود والنشر والتشغيل** — لا كود مشترك، لا نشر متقاطع.
  (رزق: مستودع `Adnan-erp-2` → Render · رياض المتقين: هذا المستودع → Cloudflare.)
- **البيانات المجموعة هنا تتدفق للجهتين:**
  - الكوربوس الشرعي المعتمد (من `/manager/training`) يكون موجوداً **في المنصّتين**.
  - **رزق يبيعه** ضمن كتالوج B2B (بهوية مجهّلة — التصدير مجهّل أصلاً).
  - **رياض المتقين يدرّب به الذكاء الاصطناعي** (نماذج تجيب عن الأسئلة الدينية بدقة).
- **الجسر حالياً يدوي:** المدير يصدّر `JSONL` من صفحة المراجعة ويُسلَّم لرزق.
  الأتمتة (API بمفتاح بين المنصّتين) مرحلة لاحقة — لا تُبنى قبل قرار صريح.

## 2) الكتب والملفات (PDF فقه ودين) — قواعد الاعتماد

- **المعلّم يرفع كتاباً** → لا يظهر ولا يُستخدم قبل **مراجعة واعتماد مدير الموقع**.
- **مدير الموقع يرفع بنفسه** → **معتمد تلقائياً** بلا موافقة إضافية.
- البنية جاهزة (`ai_documents` + R2/MEDIA) — التنفيذ الكامل (رفع + طابور اعتماد)
  يُبنى بعد استقرار النشر الآلي.
- حقوق النشر: لا يُرفع كتاب دون حقّ واضح (ملك عام / إذن ناشر / مصدر رسمي).

## 3) سياسة «موقع واحد» على Cloudflare

- النطاق `riyadalmutaqin.com` يخدمه **Worker واحد**: `riyad-almutaqin` (اسم
  `wrangler.toml` منذ البداية — النشر يحدّثه في مكانه).
- الـ Workers القديمة في الحساب (`riyadalmutaqin` بلا شرطة = بقايا الموقع الثابت
  القديم · `odd-pond-a24c` = تجريبي) **تُحذف بعد أول نشر ناجح والتحقق من الموقع** —
  حذفها لا يمسّ قاعدة البيانات (D1) ولا الملفات (R2): موارد مستقلة على مستوى الحساب.

## 3-ب) جرد النسخ القديمة قبل حذف الـ Workers (أُنجز 2026-08-12)

قورنت النسخة الثابتة القديمة (تاريخ `main` قبل التوحيد) بالنسخة الأخيرة ملفاً ملفاً:

| في القديمة | حالتها في الأخيرة |
|---|---|
| الصفحات العامة/الدخول/الأدوات (ختمة/زكاة/مساجد) | ✅ موجودة أفضل (خادم + قاعدة بيانات بدل متصفح فقط) |
| لوحات dashboard/insights/journey + auth.js (أدوار بالمتصفح) | ✅ استُبدلت بلوحات حقيقية بأدوار خادمية — لا شيء يُنقل |
| **رمز QR (qr.js)** | ✅ **نُقل** — بطاقة «امسح للدخول» في /share |
| **النشر عبر Webhooks (connect/creator.js)** | ✅ **نُقل خادمياً** — سرّ `PUBLISH_WEBHOOK_URL` يسلّم كل القنوات غير تيليجرام دفعةً لوسيط (Make/Zapier) |
| استوديو التصاميم الخمسة (studio.js) + محوّل 3 قوالب فيديو (video-studio.js) | 🔜 **مرشّح نقل لاحق** — الأخيرة فيها مونتاج ببطاقة واحدة؛ نقل التصاميم والقوالب بعد استقرار النشر |

**الخلاصة: حذف الـ Workers القديمة آمن** — كل قيّم إمّا منقول أو موثّق هنا كمرشّح نقل.

## 4) مبادئ ثابتة

- الشفافية مع المساهمين: كل مساهمة بيانات بإقرار صريح أنها تطوّر الذكاء الاصطناعي.
- لا جواب بلا مصدر في كوربوس التدريب — مفروض برمجياً في مساري المساهمة والاعتماد.
- حساب الأدمن لا يساهم بالبيانات (فصل من يبني عمّن يراقب).
- الأسرار لا تدخل git إطلاقاً — أسرار GitHub وCloudflare فقط.
