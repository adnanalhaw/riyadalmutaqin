---
description: تشغيل موقع رياض المتقين محلياً (wrangler dev) وفتحه للمعاينة
---

شغّل منصّة رياض المتقين محلياً:

1. تأكّد من تثبيت الاعتماديات: إن لم يوجد مجلّد `node_modules`، نفّذ `npm install`.
2. طبّق ترحيلات قاعدة البيانات محلياً: `npm run db:migrate:local`.
3. شغّل خادم التطوير: `npm run dev` (يعمل على `http://localhost:8787`).
4. أخبر المستخدم أن الموقع جاهز على `http://localhost:8787`، وأعطه الحسابات التجريبية:
   - معلّم: `teacher@riyad.test` / `riyad-teacher`
   - متعلّم: `student@riyad.test` / `riyad-student`
5. إن كانت الجلسة سحابية (لا متصفّح للمستخدم)، التقط لقطة شاشة للصفحة الرئيسية وأرسلها بدل ذلك.
